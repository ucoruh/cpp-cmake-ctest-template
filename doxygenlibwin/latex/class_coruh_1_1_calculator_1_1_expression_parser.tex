\doxysubsection{Detailed Description}
Parses and evaluates infix arithmetic expressions built from +, -\/, \texorpdfstring{$\ast$}{*}, /, parentheses, and (possibly decimal) numbers. 

This class used to live inline inside the calculatorapp sample application; it was moved into the library so it can be unit tested with googletest independently of the interactive app.
