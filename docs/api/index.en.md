# API documentation

The API reference is generated by **Doxygen** from the comments in the source code (classes, functions,
namespaces, call and include graphs). It is produced separately on **Windows** and on **Linux** - the
two can differ (compiler-specific code, platform macros) - and each has two parts: the libraries and the
unit-test sources.

<div class="grid cards" markdown>

-   :material-microsoft-windows: **Doxygen - Windows**

    ---

    Libraries (`utility`, `calculator`, `calculatorapp`) and the googletest sources, built by
    `7-build-all-windows.bat`.

    [:octicons-arrow-right-24: Open the Windows API docs](../reports/windows/api-doxygen.md)

-   :material-linux: **Doxygen - Linux**

    ---

    The same for Linux (native Linux and WSL), built by `./7-build-all-linux.sh`.

    [:octicons-arrow-right-24: Open the Linux API docs](../reports/linux/api-doxygen.md)

</div>

Documentation coverage (how many public symbols carry a comment) is a *report*, not API docs: see
[Which report is which?](../reports/index.md).
