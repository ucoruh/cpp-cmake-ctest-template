    Calculator - C/C++ CMake + CTest Course Project Template¶

    A complete, ready-to-fork C/C++ template: CMake + CTest + googletest, two independent report families for every check (ReportGenerator and each ecosystem's native tool), Doxygen API docs, and this site tying it all together - built as a best-practice example for RTEU course projects.

    What's in this template¶

    • CMake + CTest + googletest

      A utility library, a calculator library (fully unit-tested infix/postfix expression parsing) and a calculatorapp command-line demo, wired up with CMake and CTest. Builds on Windows (Visual Studio or Ninja + MinGW, auto-detected) and Linux/WSL (Ninja + GCC).

      Install & first build

    • Every report, two ways

      Unit-test results, code coverage and documentation coverage are each generated twice: once with ReportGenerator and once with the ecosystem's own native/older tool (OpenCppCoverage, lcov genhtml, gcovr) - so you can see how they differ.

      Which report is which?

    • API docs (Doxygen)

      Full API documentation for the library and for the test sources themselves, generated by Doxygen on both Windows and Linux, with graceful fallback if Graphviz/PlantUML are not installed.

      Browse the Windows API docs

    • This site, from scratch

      Built with MkDocs Material as a best-practice example: every HTML report gets its own page in a styled, responsive <iframe>, served locally over a tiny HTTP server and deployed automatically to GitHub Pages on every push to main.

      How this site embeds reports

    • From topic to your own project

      A worked, step-by-step walkthrough that takes a project topic from the course project guide and turns this sample into your own project: renamed targets, your own modules, tests written first.

      Topic to project guide

    • Troubleshooting, from real errors

      A table of real error messages hit while building this exact template (missing submodule, wrong CMake generator, JAVA_HOME-style PATH issues, Google Drive desktop.ini, antivirus locks...) and the exact fix for each.

      Troubleshooting

    Requirements at a glance¶

    • CMake >= 3.16 (matches the googletest submodule's own minimum; tested with a current CMake on Windows and Linux/WSL)
    • C++ standard: 17 by default (GoogleTest 1.15+ requires it)
    • GoogleTest (git submodule, pinned to a tagged release - run 0-init-submodules.bat / .sh)
    • Windows: Visual Studio 2022 Community (Desktop development with C++), or Ninja + MinGW-w64 GCC - the build scripts auto-detect which one you have
    • Linux/WSL: Ninja + GCC (the build script picks a GCC version with a matching gcov automatically)

    Full walkthrough with copy-paste commands and expected output: Install (EN) / Kurulum (TR).

    Build it yourself¶

    # Windows (cmd.exe)
7-build-app-windows.bat

# Linux / WSL
./7-build-app-linux.sh

# Open the site locally (starts a tiny HTTP server - reports use <iframe>
# and most browsers block those from a plain file:// path)
9-open-site.bat   # or ./9-open-site.sh

    Each full build takes roughly 10-20 minutes and produces, under docs/ and site/: Doxygen API docs, every unit-test/coverage/documentation-coverage report (both families), and this site. See daily workflow for the shorter day-to-day loop and private repositories & releases for how the same outputs ship as a GitHub Release (works on GitHub Free, even for a private student repository).
