This project is a C/\+C++ course-\/project template\+: a small {\ttfamily utility} library, a {\ttfamily calculator} library (with unit-\/tested infix/postfix expression parsing), a {\ttfamily calculatorapp} command-\/line demo, and a googletest suite, wired up with CMake + CTest. It generates two independent HTML reports for every report family (a third-\/party one via \href{https://github.com/danielpalme/ReportGenerator}{\texttt{ Report\+Generator}} and the ecosystem\textquotesingle{}s native/older tool), Doxygen API documentation, and a site that links all of them. See docs/reports.md ("{}\+Which report is which?"{}) once you have built it.

\hypertarget{index_autotoc_md20}{}\doxysubsection{\texorpdfstring{Github Actions}{Github Actions}}\label{index_autotoc_md20}
Three workflows under {\ttfamily .github/workflows/}\+:


\begin{DoxyItemize}
\item {\ttfamily cpp.\+yml} -\/ builds and tests (CMake configure + build Release + {\ttfamily ctest}) on every push and pull request, on Windows and Ubuntu -\/ intentionally lean, no report generation, so it stays fast and does not use many Actions minutes.
\item {\ttfamily pages.\+yml} -\/ on push to {\ttfamily main} (and manually)\+: builds the full report+site pipeline on both Windows and Ubuntu runners, merges both platforms\textquotesingle{} reports into one site, and deploys it to the {\ttfamily gh-\/pages} branch (Git\+Hub Pages). On a {\bfseries{private}} repository this step is skipped unless the repository variable {\ttfamily PAGES\+\_\+\+ON\+\_\+\+PRIVATE} is {\ttfamily true} (Git\+Hub Pages needs Git\+Hub Pro/\+Team, e.\+g. via the Student Developer Pack) -\/ see docs/guide/releases.en.md.
\item {\ttfamily release.\+yml} -\/ on a {\ttfamily v\texorpdfstring{$\ast$}{*}} tag push (or manually)\+: builds everything on both platforms and publishes a Git\+Hub Release with every asset (Windows + Linux binaries, all reports, API docs, {\ttfamily site.\+zip}). Prefer the local {\ttfamily 10-\/release.\+bat}/{\ttfamily .sh} script day to day; it does the same thing without using any Actions minutes.
\end{DoxyItemize}\hypertarget{index_autotoc_md21}{}\doxysubsection{\texorpdfstring{Build App on Windows}{Build App on Windows}}\label{index_autotoc_md21}
We have already configured script for build operations. {\ttfamily 7-\/build-\/app-\/windows.\+bat} have complete all required tasks and copy outputs to release folder. ~\newline


{\bfseries{Operation Completed in roughly 15-\/20 minutes}} (longer than earlier versions of this template, because it now also produces the native Open\+Cpp\+Coverage/genhtml reports alongside Report\+Generator\textquotesingle{}s).


\begin{DoxyItemize}
\item Clean project outputs
\item Create required folders
\item Run doxygen for documentation
\item Run coverxygen for document coverage report
\item Run Report Generator (and, if available, native lcov {\ttfamily genhtml}) for the documentation coverage report
\item Configure the project (Visual Studio if installed, else Ninja -\/ auto-\/detected)
\item Build Project Debug and Release
\item Install/\+Copy Required Library and Headers
\item Run Tests (native JUnit XML -\/\texorpdfstring{$>$}{>} {\ttfamily junit2html})
\item Run Open\+Cpp\+Coverage for coverage data collection, both a Report\+Generator HTML report and Open\+Cpp\+Coverage\textquotesingle{}s own native HTML report
\item Copy output report to webpage folder
\item Run mkdocs to build the site ({\ttfamily site/}), linking every report -\/ see {\ttfamily docs/reports.\+md}
\item Compress outputs to release folder, everything is ready for deployment.
\end{DoxyItemize}\hypertarget{index_autotoc_md22}{}\doxysubsection{\texorpdfstring{Build App on WSL/\+Linux}{Build App on WSL/Linux}}\label{index_autotoc_md22}
