\doxysubsection{Detailed Description}
A simple program to demonstrate the usage of the calculator library. 

Reads one infix expression from standard input, parses and evaluates it with \doxylink{classCoruh_1_1Calculator_1_1ExpressionParser}{Coruh\+::\+Calculator\+::\+Expression\+Parser} (library code, unit tested under src/tests/calculator), and prints the result. All expression parsing logic lives in the calculator library, not here, so it can be unit tested.
